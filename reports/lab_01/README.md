## 1. Цель работы
Реализовать и сравнить производительность последовательной и параллельной (OpenMP) версий алгоритма перемножения квадратных матриц. Провести автоматизированную верификацию результатов с помощью Python (NumPy).

## 2. Постановка задачи
- **Входные данные:** Файл, содержащий размерность $N$ и элементы двух матриц $A$ и $B$.
- **Выходные данные:** Файл с результирующей матрицей $C$, время выполнения, оценка производительности (GFLOPS).
- **Требование:** Автоматическая верификация корректности вычислений.

## 3. Алгоритм и оптимизации
Реализован классический алгоритм умножения матриц $C = A \times B$. 
Для максимизации использования кэш-памяти процессора применена **оптимизация порядка циклов `i-k-j`**. Это обеспечивает последовательный (линейный) доступ к элементам матрицы $B$, что критически снижает количество промахов кэша (cache misses).

Параллелизация выполнена с помощью директив OpenMP по внешнему циклу `i`, так как итерации независимы и не создают гонок данных (race conditions):

```cpp
#pragma omp parallel for schedule(static)
for (int i = 0; i < N; ++i) {
    for (int k = 0; k < N; ++k) {
        double a_ik = A[i * N + k];
        for (int j = 0; j < N; ++j) {
            C[i * N + j] += a_ik * B[k * N + j];
        }
    }
}
```
## 4. Методика оценки

Для оценки эффективности параллелизации используются метрики:

- **Ускорение (Speedup):** $S_p = \dfrac{T_1}{T_p}$
- **Эффективность (Efficiency):** $E_p = \dfrac{S_p}{p}$

где $T_1$ — время выполнения на 1 потоке, $T_p$ — время на $p$ потоках, $p$ — количество потоков.
