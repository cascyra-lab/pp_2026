# Лабораторная работа 1 — Перемножение матриц

## 1. Цель работы

Реализовать и измерить производительность последовательной и параллельной (OpenMP) версий программы для перемножения квадратных матриц.

## 2. Алгоритм

Используется классический алгоритм с оптимизацией порядка циклов `i-k-j` для локальности кэша.
