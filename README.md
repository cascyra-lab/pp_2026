## pp_2026 — Параллельное программирование Егоров А.Ю. 6212

Репозиторий с лабораторными работами по курсу «Параллельное программирование».

## Лабораторные работы

- **[ЛР №1 — Последовательное перемножение матриц](reports/lab_01/README.md)**
  - Программа на C/C++
  - Автоматизированная верификация (Python + NumPy)
  - Измерение производительности (GFLOPS)

- **[ЛР №2 — Параллельное перемножение матриц (OpenMP)](reports/lab_02/README.md)**
  - Модификация с директивами OpenMP
  - Серия экспериментов: N = 200...2000, p = 1, 2, 4, 8
  - Анализ ускорения и эффективности

- **[ЛР №3 — Распределённое перемножение матриц (MPI)](reports/lab_03/README.md)**
  - Распределённая версия с использованием MPI
  - Запуск на суперкомпьютере «Сергей Королёв» (ССАУ) через SLURM
  - Серия экспериментов: N = 200...2000, p = 1, 2, 4, 8

- **[ЛР №4 — Параллельное перемножение матриц (CUDA)](reports/lab_04/README.md)**
  - Реализация CUDA-ядра для GPU
  - Эксперименты с конфигурациями сетки блоков (16x16, 32x32)
  - Анализ производительности (GFLOPS) и влияния размера блока

- **[ЛР №5 — Параллельная генерация фрактала Мандельброта (Stanford CS149)](reports/lab_05/README.md)**
  - Реализация из курса Stanford CS149 Assignment 1
  - Многопоточность через std::thread (C++14)
  - Анализ дисбаланса нагрузки и оптимизация через interleaved row assignment
  - Эксперименты: 1, 2, 4, 8, 16 потоков на двух видах фрактала

## Структура проекта

- `src/` — исходный код программ (ЛР 1-4)
- `cs149_prog1_mandelbrot/` — исходный код по Stanford CS149 Program 1
- `scripts/` — вспомогательные скрипты (генерация данных, построение графиков)
- `results/` — результаты экспериментов (CSV-таблицы, графики)
- `reports/` — отчёты по лабораторным работам
